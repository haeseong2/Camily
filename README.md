# 🏕 Camily - Camping Reservation Web

> キャンプ用品の予約・購入が可能なWebサービス

---

## 📌 概要
本プロジェクトは、韓国のキャンプ用品レンタルサイトを参考に開発した  
**キャンプ用品の予約・購入システム**です。

商品閲覧から予約、決済までの流れを一貫して体験できる  
実用的なWebサービスを目指しました。

---

## 🚀 主な機能
- 🏕 キャンプ用品一覧表示  
- 🔍 商品検索機能  
- 📄 商品詳細ページ  
- 🛒 カート機能  
- 💳 決済機能（簡易実装）  
- 📦 注文・予約管理  

---

## 🛠 Tech Stack
**Backend**
- Java  
- Spring Framework  

**Frontend**
- HTML / CSS / JavaScript  
- JSP  

**Database**
- Oracle  

---

## 💡 特徴
- 🛒 購入〜決済までの一連のフローを実装  
- 📊 実サービスを意識した構成  
- 💻 フルスタック開発経験  
- 🔎 商品検索・管理機能  

---

## 🎯 工夫した点
- ユーザーの操作フローを意識し、  
  **商品選択 → カート → 決済までの流れを最適化**
- 実際のECサイトを参考に、  
  **画面遷移とデータ構造を設計**
- DB設計を工夫し、  
  **注文・商品情報を効率的に管理**
